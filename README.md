# Militree (部隊組織図表示ツール)

　**Militree** は、CSVデータから複雑な部隊組織や人事データを読み込み、直感的なツリー形式で可視化するブラウザベースの組織図ビュアーです。

　通常の階層構造だけでなく、「副連隊長」「最先任」「本部付」といった幕僚・補佐（アシスタント）ポストを本部長の直下左右に配置する高度な独自レイアウトを備えています。

## ✨ 主な機能

* **📂 CSVデータの動的読み込み**
    * 所定のフォーマットのCSVファイルを読み込むだけで、即座に組織図を自動生成します。


* **🌳 高度なツリーレイアウト (GoJS)**
    * 通常の指揮系統（縦割り）と、幕僚・補佐系統（横出し）を視覚的に分離して描画します。


* **🔍 強力な検索とフォーカス機能**
    * 氏名、役職、部隊名から対象者を検索し、該当部隊にズームします。
    * 右クリックメニューから「この部隊をルートとして隷下を表示」を選ぶことで、特定の中隊や小隊だけを切り出して表示可能です。


* **📊 リアルタイム人員集計（サイドバー詳細表示）**
    * 部隊をクリックするとサイドバーが開き、配下を含む組織全体の「部隊規模（総員・実員・欠員）」「階級区分（幹部・准曹士など）」「軍種別」「男女別」を瞬時に集計して表示します。兼務や欠員も正確に除外・計算されます。


* **👁️ ノード内表示のカスタマイズ**
    * 画面上部のチェックボックスで、役職・軍種・階級・氏名などの表示/非表示をワンクリックで切り替えられます。


* **💾 SVGエクスポート**
    * 現在表示されている組織図をSVG画像形式でダウンロード・保存できます。


* **🛠️ スムーズな開閉コントロール**
    * 「全展開」「全体表示に戻す」ボタンのほか、ノードの `[+]` ボタンを押すと「直下の階層のみ」が安全に開くように制御されています。



---

## 🛠️ 動作環境・依存ライブラリ

本ツールはウェブブラウザ上で動作します。HTMLファイルと同一ディレクトリ（または指定パス）に以下のライブラリが必要です。

* **[GoJS](https://gojs.net/)** (`go.js`): 組織図の描画エンジン
* **[Papa Parse](https://www.papaparse.com/)** (`papaparse.min.js`): 高速なCSVパース用ライブラリ

## 📝 CSVデータのフォーマット

読み込ませるCSVファイルは、以下のカラム名（ヘッダー行）を**完全に一致**させる必要があります。

### 必須ヘッダー（1行目）

```csv
番号,部隊コード,部隊名,上級部隊コード,配置区分,役職,所属区分,軍種,階級,氏名,性別,備考

```

### 各カラムの役割

* **番号**: メンバーの一意のID（集計時に実員を計算するためのキーにもなります）
* **部隊コード** *(必須)*: ノードの識別子。半角英数字推奨（例: `1i`, `1Co`）
* **部隊名**: 画面に表示される部隊の名称
* **上級部隊コード**: 親部隊の「部隊コード」。一番上のトップ部隊は空欄、または「なし」とします。
* **配置区分**:
    * `assistant` または `スタッフ`、`補佐` と入力すると、そのノードは親部隊の横（幕僚位置）に配置されます。
    * それ以外（空欄など）は通常の隷下部隊として下に配置されます。
* **役職**: 役職名（例: 連隊長、中隊長、情報係）
* **所属区分**: `主務`, `兼務`, `欠員` などを指定。（「兼務」「欠員」は実員集計から除外・特別扱いされます）
* **軍種**: `陸`, `海`, `空`, `統`, `内` など
* **階級**: 階級名（例: 1佐、曹長、事務官）。この文字列をもとに「幹部・准曹士・事務官等」を自動判別します。
* **氏名**: 氏名。欠員の場合は「欠員」や「未定」と入力可能です。
* **性別**: `男` または `女`
* **備考**: 任意のテキスト

### データ作成のルール・注意点

* 空の部隊（メンバーなし）を作る場合は、役職・氏名などを空欄にして「部隊コード」と「部隊名」だけを記述してください。
* 人員を正しく集計するため、同じ部隊コードに対して複数人が所属する場合は、**部隊コード・部隊名を同じにして行を複数作成**してください。

## 🚀 使い方

1. `Militree.html` をウェブブラウザ（Chrome, Edge等）で開きます。
2. 画面左上の **「ファイルを選択 (参照)」** ボタンから、作成したCSVデータを読み込みます。
3. 組織図が自動的に描画され、トップノードが画面中央にフォーカスされます。
4. **ノードの操作**:
    * `[+]` / `[-]` ボタン: 1階層ずつ部隊を展開/折りたたみます。
    * **左クリック**: 右側のサイドバーが開き、詳細な人員集計と名簿を確認できます。
    * **右クリック**: メニューが開き、特定の部隊だけを切り出して表示（フォーカス）できます。
5. **全体表示に戻す**: 右クリックでフォーカスした状態から、元の全体図に戻します。
6. **全展開**: 現在表示されている範囲を末端まで一気に展開します。

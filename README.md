# 🌲 Militree (ミリツリー)
> **Military Unit & Organization Visualizer**  
> *CSVを1枚読み込むだけで、全Unit（部隊）のOrganization（組織）が爆速で生えてくるビジュアライザ*

[![GitHub Repository](https://img.shields.io/badge/GitHub-military--org--chart-blue)](https://github.com/Ken-zen1nyo/military-org-chart)

---

## 概要 (Overview)

**Militree (ミリツリー)** は、CSVフォーマットの人事・構造データを読み込み、複雑な階層構造を持つ部隊組織図（Military Organization Chart）をブラウザ上に動的かつインタラクティブに描画・管理するためのWebアプリケーションです。

部隊（Unit）ごとの階層構造、補佐（Assistant）の配置、幹部・准曹士・事務官の自動区分、兼務者の集計除外ロジックなど、防衛・ミリタリー組織ならではの特殊な人事体系に完全対応しています。

また、外部インターネット接続のない**クローズド環境（閉域網・オフライン環境）**での運用を前提に設計されており、安全かつ軽量に動作します。

## 主な機能

- **CSVデータのインポート**: 所属メンバー、役職、階級、軍種、性別などのデータが含まれるCSVを読み込み、自動でツリー構造の組織図を構築します。
- **インタラクティブな組織図 (GoJS使用)**:
  - ノード（部隊）の展開・折りたたみ
  - ドラッグ＆ドロップでのノード移動
  - 特定の部隊をルートとしてその下位のみを表示する「フォーカス表示」
- **詳細サイドバー & 集計表示**:
  - ノードをクリックすると、当該部隊単体の人数や、配下を含めた集計（総人数、実人数、階級区分別、軍種別、男女別）をCSS Gridできれいに整えたタブ形式で表示。
  - 兼務メンバーの除外カウントなど、複雑な人事集計に対応。
  - 所属メンバーの一覧表を表示。
- **柔軟な表示切り替え**:
  - ノード内に表示する項目（役職・軍種・階級・氏名・性別・備考）をチェックボックスでリアルタイムに切り替え可能。
- **検索機能**:
  - 氏名、役職、部隊名などでリアルタイムにノードをハイライト・フォーカス検索。
- **エクスポート機能**:
  - 現在の組織図をSVG形式で保存可能。

## CSVファイルのデータ構造・仕様

読み込ませるCSVファイルには、以下のヘッダー（列名）およびデータ構造が必要です。

### カラム仕様一覧（左から順）

| 列名 (Header) | 必須/任意 | 説明 | 例 |
| :--- | :--- | :--- | :--- |
| `番号` | 任意 | 連番やメンバーの識別ID、管理番号など | 001、A-01 |
| `部隊名` | **必須** | 所属する部隊・組織の名称 | 第1連隊、本部管理中隊 |
| `親部隊名` | **必須** | 上位部隊の名称（最上位ルートの場合は空欄または「なし」） | 師団司令部、なし |
| `配置区分` | 任意 | スタッフや補佐として別枠に配置する場合に `assistant` を指定 | `assistant` （または空欄） |
| `役職` | 任意 | 役職名 | 中隊長、副中隊長、最先任、人事係 |
| `所属区分` | 任意 | `主務` または `兼務`（兼務を指定すると、集計時の実人数から除外されます） | 主務、兼務 |
| `軍種` | 任意 | 所属する軍種・自衛隊区分 | 陸、海、空、統 |
| `階級` | **必須** | 階級または役職区分（幹部・准曹士の自動判定に使用されます） | 1佐、1尉、3曹、事務官 |
| `氏名` | **必須** | メンバーの氏名 | 山田 太郎 |
| `性別` | 任意 | 性別 | 男、女 |
| `備考` | 任意 | 自由記載欄（特記事項など） | 兼務（本部付） |

## 使い方

1. 本リポジトリのファイルをすべて同一フォルダに配置します。
2. `libraly/` フォルダの中に必要なJSファイル（`go.js`, `papaparse.min.js`）が配置されていることを確認します（※オープン環境の場合はCDN等へ書き換え）。
3. `Militree.html` をブラウザ（Chrome, Edge, Firefoxなど）で直接開きます。
4. 画面上部の **ファイルを選択** ボタンから、上記の仕様に準拠したCSVファイルを読み込みます。

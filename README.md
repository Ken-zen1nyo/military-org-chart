# Militree / Militree+ (部隊組織図＆出欠・その他管理ツール)

**Militree（ミリツリー）** およびその発展版である **Militree+** は、CSVデータから複雑な部隊組織や人事データを読み込み、直感的なツリー形式で可視化するブラウザベースの組織図ビュアーです。

通常の階層構造だけでなく、「副連隊長」「最先任」「本部付」といった幕僚・補佐（アシスタント）ポストを本部長の直下左右に配置する高度な独自レイアウトを備えています。さらに、Militree+では複数中隊のデータ統合、実員の自動集計、およびリアルタイムの出欠（事故）や特記事項の管理機能を提供します。

## ✨ 主な機能

* **📂 複数CSVファイルの一括読み込み**
    * 中隊ごとに分割されたCSVファイルを複数同時に選択・読み込み、1つの大きな組織図として自動的に結合・描画します。


* **🌳 高度なツリーレイアウト (GoJS)**
    * 通常の指揮系統（縦割り）と、幕僚・補佐系統（横出し）を視覚的に分離して描画します。


* **🔍 強力な検索とフォーカス機能**
    * 氏名、役職、部隊名、不在理由、その他項目などから対象者を検索し、該当部隊にズームします。
    * 右クリックメニューから「この部隊をルートとして隷下を表示」を選ぶことで、特定の中隊や小隊だけを切り出して表示可能です。


* **📊 リアルタイム人員＆出欠・その他集計（左右のサイドバー）**
    * **右クリックまたはシングルクリック**: 右サイドバーが開き、配下を含む組織全体の「部隊規模（総員・実員・欠員・事故・その他）」「階級区分」「軍種別」「男女別」を瞬時に集計します。
    * **ダブルクリック（または右クリックメニュー）**: 左サイドバーが開き、選択した部隊の「総員」「事故」「その他」「現在員」のほか、不在者や該当者の氏名・理由の一覧を部隊名付きで確認できます。


* **👁️ ノード内表示のカスタマイズ**
    * 画面上部のチェックボックスで、役職・軍種・階級・氏名・不在状況・備考、そして「集計」結果そのものの表示/非表示をワンクリックで自由に切り替えられます。


* **💾 SVGエクスポート**
    * 現在表示されている組織図をSVG画像形式でダウンロード・保存できます。


* **🛠️ スムーズな開閉コントロール**
    * 「全展開」「全体表示に戻す」ボタンのほか、ノードの `[+]` ボタンを押すと「直下の階層のみ」が安全に開くように制御されています。



---

## 🛠️ 動作環境・依存ライブラリ

本ツールはウェブブラウザ上で動作します。HTMLファイルと同一ディレクトリ（または指定パス）に以下のライブラリが必要です。

* **[GoJS](https://gojs.net/)** (`go.js`): 組織図の描画エンジン
* **[Papa Parse](https://www.papaparse.com/)** (`papaparse.min.js`): 高速なCSVパース用ライブラリ

## 📝 CSVデータのフォーマット

読み込ませるCSVファイルは、以下のカラム名（ヘッダー行）を**完全に一致**させる必要があります。

### 必須ヘッダー（1行目）

```csv
番号,部隊コード,部隊名,上級部隊コード,配置区分,役職,所属区分,軍種,階級,氏名,性別,備考,不在,理由等,その他

```

### 各カラムの役割

* **番号**: メンバーの一意のID（集計時に実員を計算するためのキーにもなります）
* **部隊コード** *(必須)*: ノードの識別子。半角英数字推奨（例: `1i`, `1Co`）
* **部隊名**: 画面に表示される部隊の名称
* **上級部隊コード**: 親部隊の「部隊コード」。一番上のトップ部隊は空欄、または「なし」とします。
* **配置区分**:
    * `assistant` または `スタッフ`、`補佐` と入力すると、そのノードは親部隊の横（幕僚位置）に配置されます。
    * それ以外（空欄など）は通常の隷下部隊として下に配置されます。
* **役職**: 役職名（例: 連隊長、中隊長、情報係）
* **所属区分**: `主務`, `兼務`, `欠員` などを指定。（「兼務」「欠員」は実員集計から除外・特別扱いされます。兼務者が不在の場合は**主務の行**に入力してください）
* **軍種**: `陸`, `海`, `空`, `統`, `内` など
* **階級**: 階級名（例: 1佐、曹長、事務官）。この文字列をもとに「幹部・准曹士・事務官等」を自動判別します。
* **氏名**: 氏名。欠員の場合は「欠員」や「未定」と入力可能です。
* **性別**: `男` または `女`
* **備考**: 任意のテキスト
* **不在**: 留守や欠席の状況（例: `代休`, `年休`, `特休`, `出張` など、フリー入力可）
* **理由等**: 不在の具体的な理由（フリー入力）
* **その他**: 事故以外の特記事項やフリー項目（入力すると左サイドバーの「その他の内訳」にリストアップされます）

## 🚀 使い方

1. `Militree+.html` をウェブブラウザ（Chrome, Edge等）で開きます。
2. 画面左上の **「ファイルを選択」** ボタンから、複数のCSVファイル（各中隊のデータなど）を**まとめて一括選択**して読み込みます。
3. 組織図が自動的に結合・描画され、トップノードが画面中央にフォーカスされます。
4. **ノードの操作**:
    * `[+]` / `[-]` ボタン: 1階層ずつ部隊を展開/折りたたみます。
    * **シングルクリック**: 右側のサイドバーが開き、詳細な人員集計と名簿を確認できます。
    * **ダブルクリック**（または右クリックメニュー）: 左側のサイドバーが開き、出欠状況（総員・事故・その他・現在員・不在理由）を確認できます。
    * **右クリック**: メニューから特定部隊のルート表示や全体表示への復帰が可能です。
5. **表示切り替え**: 上部のチェックボックスで、ノード内の情報（集計や不在の有無など）をダイレクトにON/OFFできます。
